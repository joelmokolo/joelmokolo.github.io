# Excel foundations — Assignment 1

**Type:** Training assignment · Excel skills refresher  
**Context:** TS Academy data analytics training, with guidance from Ezekiel Aleke.  
**File:** [Open the workbook](corrected_Joel_Mokolo_Assignment_1.xlsx)

## What I practised

I used a 100-row employee practice dataset to refresh Excel text handling and calculated fields. The workbook separates first and last names, constructs email addresses, changes department text to upper, lower and proper case, and trims name text. The formulas remain in the workbook so they can be inspected rather than inferred from a screenshot.

## How to inspect it

Open the `Assignment 1` sheet. The source fields start in columns A–H; the derived fields are in columns I–O. Compare a few rows with the source values and inspect the formulas in the formula bar.

## Scope and limitations

This is a learning exercise, not a production HR analysis. The employee records and generated email addresses are part of the supplied practice workbook; they are not offered as verified real-world contacts. The workbook is shared as submitted, without claiming independent data sourcing or operational impact.
