# Logistics Operations Intelligence — capstone

**Status:** In development  
**Focus:** SQL, data quality, relational modelling and operational analysis  
**Dataset:** Supplied logistics operations practice package: 14 CSV tables and one key guide.

## Business question

How can a logistics operator improve delivery reliability and fleet efficiency while understanding the costs behind each delivery?

## Our build plan

1. Inventory the tables and check data quality.
2. Import the CSVs into a relational database.
3. Test keys, relationships and the level of detail in each table.
4. Write SQL to investigate deliveries, routes, fuel, maintenance and fleet use.
5. Validate the results and explain what the operator could do with them.
6. Publish the queries, findings and a clear dashboard or report.

## Current status

The dataset has been received and the project is beginning. Findings and finished analyses will be added as we build and verify them.
